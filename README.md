# Anquestry

Anquestry adds a compact, collapsible quest-chain flyout to the quest log and quest-giver window in World of Warcraft Forever. See prerequisites, follow-up quests, and remaining XP at a glance. Click a quest row for its start and turn-in details and a copyable Wowhead link.

## Getting started

Install and enable Anquestry and the Forever build of **QuestieDB**. The first time you select a quest, click **Build quest chain cache**. Anquestry indexes your local QuestieDB data so chains load quickly as you switch quests. WoW saves the cache when you log out or reload.

Open **Settings → AddOns → Anquestry** or type `/anquestry` to change settings or rebuild the cache.
